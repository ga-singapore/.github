# GA Singapore

This organization contains **course and delivery repositories for programs run by the GA Singapore campus**.

## Purpose

To support local program delivery for remote, in-person, or campus-based cohorts.

## What Belongs Here

- Course repositories used by the Singapore campus
- Cohort-specific delivery repositories

## What Does NOT Belong Here

- Global reusable curriculum modules
- Enterprise program templates managed centrally

## Key Characteristics

- Repositories can be **Public** or **Internal**
- Students are added to repositories for their cohort as **outside contributors**
- Allows flexibility for local delivery models
- Supports campus-specific workflows

## How to Work in This Org

- Follow local campus delivery practices
- Maintain clear separation between cohorts
- Add students only to relevant repositories

## Access Model

- Managed by Singapore staff
- Students are added per cohort as needed
