# Singapore website repositories

The Singapore organisation has set up private repositories for the website code. Sites are grouped by purpose, including the main marketing site, public course and resource sites, and separately managed workshop sites. Existing course and cohort guidance is unchanged.

If you maintain a site, start with the [private website hub](https://github.com/ga-singapore/web-hub). It lists the repositories and what each contains, and explains how to set up your tools, open a pull request, and check a release. The link requires access from a Singapore organisation maintainer.

The website repositories are in place. The production deployment switch is still pending; check the private hub for status before releasing.
